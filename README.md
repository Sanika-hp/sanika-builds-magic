# Sanika's AI Playground

Build a modern, highly animated, funny, interactive personal portfolio website for **Sanika H P**, an undergraduate Artificial Intelligence & Data Science student at **REVA University, Bengaluru**.

## DESIGN STYLE

Create a **WHITE / LIGHT THEME ONLY**.

The website should feel inspired by the clean, premium interfaces of modern AI website builders such as Lovable, v0 and Google AI Studio — but do NOT copy their exact design.

Make it:

* Clean
* Minimal
* Premium
* Playful
* Funny
* Interactive
* Highly animated
* Student-friendly
* Professional enough for recruiters

Use plenty of white space with black/dark text and subtle accent colors.

Avoid:

* Dark mode
* Heavy gradients
* Overly corporate design
* Clutter
* Excessive glassmorphism
* Generic portfolio templates
